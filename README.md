# tuneBloom for Android: downloads

This repository only holds the official tuneBloom Android app releases (APK files).
It contains no source code.

**Get the app at https://tunebloom.cloud/#app-download**, which always links to the newest version.

Each release includes:

- `TuneBloom-<version>-arm64.apk`: 64-bit, for most phones
- `TuneBloom-<version>-armv7.apk`: 32-bit, for older phones
- `SHA256SUMS.txt`: SHA-256 checksums and the tuneBloom signing certificate fingerprint

Every APK is signed with the tuneBloom release key. Its certificate SHA-256 is
`c45cdbf1a28146cdb6e85bc4e349e62520a05c0f9455188dd8d9a010f5791bb1`.
